# 史前禁区 · Museum Lockdown

一款零依赖、可直接在现代浏览器运行的原创 H5 第一人称射击原型。地图采用原创恐龙博物馆布局，不包含《穿越火线》或《反恐精英》的原始素材、标识和关卡文件。

## 运行

浏览器的 ES Module 需要通过 HTTP 访问。在项目目录执行：

```bash
python3 -m http.server 8080
```

然后打开 <http://localhost:8080>。

## 操作

- `W/A/S/D`：移动
- 鼠标：转向 / 瞄准
- 左键：射击、投掷或挥刀
- 右键：巴雷特 8 倍镜
- `1`：巴雷特 M82A1
- `2`：M67 手雷
- `3`：瑞士军刀
- `G`：快速投掷手雷
- `F`：靠近坦克时上车 / 下车
- `Esc`：暂停

触屏设备提供左侧虚拟摇杆、滑动瞄准以及开火、开镜、手雷和载具交互按钮。

## 玩法

玩家属于 4 人海豹突击队，对抗 4 名恐怖分子。双方 AI 会移动、搜索、射击和投掷手雷；阵亡后自动重新部署。单局 5 分钟，率先取得 15 次击杀的一方获胜。武器、手雷与坦克炮弹均无限。
